# 🦜 LangChain

## Introduction

**LangChain** is an open-source framework for building applications powered by **Large Language Models (LLMs)**.

It provides developers with tools and components that make it easier to connect LLMs with **prompts, data, tools, memory, APIs, and other application components**.

Instead of building an AI application completely from scratch, LangChain provides reusable building blocks that help developers create more powerful and structured AI applications.

## Why Learn LangChain?

Learning LangChain helps developers understand how to build applications around LLMs, such as:

* 🤖 AI Chatbots
* 📚 Question Answering Systems
* 🔎 Retrieval-Augmented Generation (RAG) applications
* 🧠 AI Agents
* 📄 Document-based AI applications
* 🔗 LLM workflows and pipelines
* 🛠️ AI applications connected with external tools and APIs

## What Can We Build with LangChain?

With LangChain, we can create applications where an LLM can:

1. Understand user input
2. Follow structured prompts
3. Work with external data
4. Retrieve relevant information
5. Use tools and APIs
6. Perform multiple steps in a workflow
7. Generate useful responses

## Basic Idea

A simple way to understand LangChain is:

```text
User
  ↓
Prompt
  ↓
LangChain
  ↓
LLM
  ↓
Response
```

For more advanced applications:

```text
User
  ↓
Prompt
  ↓
LangChain
  ↓
LLM + Tools + Data + Memory
  ↓
Useful AI Application
```
